# 告警码字典

> 依据《智能运维IT资产本体建模方案V2.0》附录 A（31 条）+ TABLESPACE_FULL（D1 规则前件所需）。
> 平台落库位置：`ops/alert_causality.py` ALERT_CODE_DICTIONARY（共 32 条）。

## 回填命令

```bash
python manage.py backfill_alert_codes            # 执行回填（仅处理 alert_code 为空的告警）
python manage.py backfill_alert_codes --dry-run  # 仅统计预览
```

## 规则种子

```bash
python manage.py seed_alert_causality_rules      # 幂等种入默认 L1 因果规则
```

## 告警码清单

| 告警码 | 中文名 | 因果级别 | 典型根因 |
| --- | --- | --- | --- |
| HOST_DOWN | 主机宕机/离线 | 根因 | 硬件故障、断电、OS崩溃 |
| STORAGE_IO_TIMEOUT | 存储卷IO超时 | 根因 | 存储性能劣化、链路异常 |
| STORAGE_FULL | 存储卷写满 | 根因 | 容量耗尽 |
| PORT_DOWN | 交换机端口Down | 根因 | 链路/光模块/对端故障 |
| PACKET_LOSS_HIGH | 端口丢包率过高 | 根因 | 链路质量、拥塞 |
| TABLESPACE_FULL | 表空间使用率超限 | 根因 | 表空间使用率>99%（D1 前件） |
| NETWORK_ABNORMAL | 主机网络异常 | 派生(L1) | 交换机端口故障 |
| ORA-03113 | 通信通道EOF（连接中断） | 派生(L2) | 网络闪断、会话被切断 |
| ORA-12535 | TNS操作超时 | 派生(L2) | 网络不通、防火墙拦截 |
| ORA-03137 | TTC协议内部错误 | 派生(L2，概率性) | 常伴网络闪断/空闲连接被中段设备切断 |
| ORA-12541 | TNS:no listener | 派生(L1) | 监听进程宕机 |
| ORA-12514 | 监听不认识该service | 派生(L2) | 实例未注册/服务名错误 |
| ORA-01653 | 表空间无法扩展 | 派生(L1) | 表空间使用率>99% |
| DB_HANG | 数据库挂起 | 派生(L1) | 归档目的地满 |
| DB_IO_DEGRADED | 数据库IO性能劣化 | 派生(L1) | 存储IO超时 |
| DB_WRITE_BLOCKED | 数据库写入阻塞 | 派生(L1) | 存储卷写满 |
| INSTANCE_DOWN | 数据库实例宕机 | 根因/派生 | 实例崩溃或主机宕机 |
| INSTANCE_UNREACHABLE | 实例不可达 | 派生(L1) | 主机宕机 |
| BLOCKING_LOCK | 阻塞锁/锁等待 | 根因 | 长事务、死锁 |
| DB_LOCK_TIMEOUT | 锁等待超时 | 派生(L2) | 阻塞锁传导 |
| LISTENER_DOWN | 监听进程宕机 | 根因 | 监听进程异常退出 |
| SERVICE_UNREGISTERED | 服务未注册到监听 | 根因 | 实例未注册/动态注册失败 |
| ARCHIVE_DEST_FULL | 归档目的地满 | 根因 | 归档磁盘耗尽 |
| PROCESS_DOWN | 进程宕机 | 根因 | 进程异常退出 |
| THREAD_POOL_EXHAUSTED | 线程池耗尽 | 根因 | 流量突增、慢请求堆积 |
| CONN_POOL_EXHAUSTED | 连接池耗尽 | 根因 | 连接泄漏、慢SQL |
| API_TIMEOUT | 接口超时 | 派生 | 中间件/数据库资源耗尽 |
| ACCESS_FAILURE | 业务访问失败 | 派生(L1) | WebServer宕机 |
| BUSINESS_ERROR | 微服务业务错误 | 派生/根因 | 数据库不可用或代码异常 |
| TRANSACTION_FAILURE | 业务交易失败 | 派生(L1) | 微服务业务错误 |
| TRANSACTION_TIMEOUT | 业务交易超时 | 派生(L1) | 微服务API超时 |
| DB_PERF_RISK | 数据库性能风险（候选） | L3候选 | 主机资源耗尽嫌疑 |

## 默认 L1 因果规则（与 V2.0 §4.3 规则 ID 对齐）

| 规则 ID | 前件 | 派生 | 关系 |
| --- | --- | --- | --- |
| B3 | LISTENER_DOWN | ORA-12541 | 资源直配 |
| D1 | TABLESPACE_FULL | ORA-01653 | contains 上溯 ≤5 跳 |
| D2 | STORAGE_FULL | DB_WRITE_BLOCKED | depends_on 上溯 ≤5 跳 |
| D2b | STORAGE_IO_TIMEOUT | DB_IO_DEGRADED | depends_on 上溯 ≤5 跳 |
| D3 | ARCHIVE_DEST_FULL | DB_HANG | depends_on 上溯 ≤5 跳 |
| B1 | HOST_DOWN | INSTANCE_UNREACHABLE | hosted_on 上溯 ≤5 跳 |
| B2 | PORT_DOWN / PACKET_LOSS_HIGH | NETWORK_ABNORMAL | connects_to 上溯 ≤5 跳 |
