# 运维助手日常对话问题清单

> 基于本地接入数据特征定制：Zabbix 18 台主机（交换机/数据库/虚拟化）、iTop CMDB（订单/支付业务）、Mimir/Loki/Tempo、K8s 集群。
> 每条问题标注：预期助手行为（调用的工具与返回的证据）。

## 一、告警总览与查询

| # | 问题原句 | 预期助手行为 |
| --- | ---- | ---- |
| 1 | 查询告警信息 | `query_alerts_tool`：列出当前告警（含 Zabbix 告警、级别、关联主机） |
| 2 | 当前有哪些严重告警？ | `query_alerts_tool`（level=critical）：过滤严重告警 |
| 3 | 今天有哪些告警？ | `query_alerts_tool`（date_filter=today） |
| 4 | Oracle19C 这台主机有什么告警？ | `query_alerts_tool`（关键词搜索主机名），如无平台告警可追问 Zabbix 侧 |
| 5 | 最近 7 天告警多吗？趋势如何？ | 告警统计 + `query_alerts_tool` 按天分布 |
| 6 | Zabbix 上当前有哪些问题？ | `query_zabbix_problems_tool`：原始问题列表（严重度/确认状态） |
| 7 | 有哪些未确认的告警？ | 平台告警未确认筛选 + Zabbix acknowledged=false |
| 8 | 告警按级别统计一下 | `query_alerts_tool` 级别分布（critical/warning/info 计数） |

## 二、Zabbix 主机监控

| # | 问题原句 | 预期助手行为 |
| --- | ---- | ---- |

| 16 | 主机上有哪些监控项？ | `query_zabbix_items_tool`：监控项列表与最新值 |
