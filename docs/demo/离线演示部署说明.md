# SxDevOps 离线演示部署说明

面向客户现场演示的单容器离线部署方案：**全部模拟数据 + 内置离线模拟模型引擎（AI 问答零 API Key、零网络）+ 一键启动脚本**。

---

## 一、方案概览

```
┌───────────────────────────────┐
│        sxdevops-demo 镜像      │
│  Daphne ASGI :8000            │
│  Vue 3 前端 + Django 后端      │
│  SQLite（卷持久化）            │
│  内置离线模拟模型引擎           │
│  (AI 问答无需任何 API Key)     │
└───────────────────────────────┘
         docker load 导入
    客户笔记本（Docker Desktop）
```

| 特性 | 说明 |
|------|------|
| 单容器 | 无 MySQL / Redis 依赖，内存缓存 + 内存通道层 |
| 离线 AI | `SXDEVOPS_DEMO_MODE=1` 启用确定性模拟模型，AI 问答真实调用平台工具查询演示数据后按模板生成答案 |
| 全量演示数据 | 告警/日志/发布/CMDB/拓扑/Zabbix 模拟监控/事件墙/工单/多云 等自动种子 |
| 一键启动 | `start-demo.ps1`：load → run → 等待就绪 → 打开浏览器 |
| 数据持久 | 数据卷保存演示数据与聊天历史；重启不清空 |

---

## 二、准备阶段（本地/公司，需网络）

### 1. 构建镜像

```bash
cd <项目根目录>
docker compose -f docker-compose.demo.yml build
```

### 2. 导出镜像包

```bash
docker save sxdevops-demo:latest -o sxdevops-demo.tar
```

### 3. 拷贝到 U 盘

```
sxdevops-demo.tar          # 镜像包（约 1GB）
tools/demo/start-demo.ps1  # 一键启动脚本
```

> 建议出发前在本机完整演练一遍：导入 → 启动 → 按《DEMO讲解脚本》走查全部页面与 6 个 AI 问答。

---

## 三、现场启动（客户笔记本，离线）

**前置条件**：Windows 10+，Docker Desktop 已安装并启动（镜像包已预置，无需拉取任何东西）。

### 方式一：一键脚本（推荐）

```powershell
# 将 U 盘中的两个文件放到同一目录，在 PowerShell 中执行：
.\start-demo.ps1
```

脚本自动完成：Docker 检查 → 镜像导入 → 容器启动 → 等待就绪 → 打开浏览器。

### 方式二：手动命令

```powershell
docker load -i sxdevops-demo.tar
docker run -d --name sxdevops-demo --restart unless-stopped -p 8000:8000 `
  -v sxdevops-demo_data:/data `
  -e DATABASE_ENGINE=sqlite -e SQLITE_NAME=/data/db.sqlite3 -e SQLITE_TIMEOUT=20 `
  -e SXDEVOPS_WAIT_FOR_DB=0 -e SXDEVOPS_MIGRATE=1 `
  -e SXDEVOPS_SEED_DATA=1 -e SXDEVOPS_SEED_TEMPLATES=1 `
  -e SXDEVOPS_DEMO_MODE=1 -e DEEPAGENTS_FALLBACK_ON_ERROR=0 `
  -e SECRET_KEY=sxdevops-offline-demo -e DEBUG=0 `
  -e ALLOWED_HOSTS='*' -e CORS_ALLOW_ALL_ORIGINS=1 `
  sxdevops-demo:latest
```

### 等待就绪

首次启动执行迁移 + 种子数据，约 **30-90 秒**。观察：

```bash
docker logs -f sxdevops-demo
```

看到 daphne 监听日志后即可访问。

- 访问地址：`http://localhost:8000`（端口冲突时用 `-Port 8001` 换端口）
- 登录账号：**admin** / **Admin@123456**（或 ops_demo 等演示账号）

## 五、现场运维速查

```powershell
# 查看日志
docker logs -f sxdevops-demo

# 停止 / 再次启动（数据保留）
docker stop sxdevops-demo
docker start sxdevops-demo

# 恢复初始演示状态（清空数据卷重新种子）
docker stop sxdevops-demo
docker rm sxdevops-demo
docker volume rm sxdevops-demo_data
.\start-demo.ps1

# 端口被占用时更换端口
.\start-demo.ps1 -Port 8001
```

## 六、环境变量参考（demo 模式）

| 变量 | 值 | 说明 |
|------|-----|------|
| `SXDEVOPS_DEMO_MODE` | `1` | 启用内置离线模拟模型（核心开关，关闭则 AI 需真实模型） |
| `DEEPAGENTS_FALLBACK_ON_ERROR` | `0` | 禁止回退 legacy 引擎发起网络请求 |
| `DATABASE_ENGINE` | `sqlite` | SQLite 数据库 |
| `SQLITE_NAME` | `/data/db.sqlite3` | 数据卷内持久化 |
| `SXDEVOPS_WAIT_FOR_DB` | `0` | 跳过 MySQL 等待（单容器无 MySQL） |
| `SXDEVOPS_SEED_DATA` / `SXDEVOPS_SEED_TEMPLATES` | `1` | 自动种子演示数据（有 .seeded 标记时跳过） |
| `SXDEVOPS_RESEED` | `1` | 强制重新种子（演示数据重置为初始状态） |

## 七、常见问题

| 现象 | 处理 |
|------|------|
| 端口 8000 被占用 | `start-demo.ps1 -Port 8001`，访问 `http://localhost:8001` |
| 未检测到 Docker | 启动 Docker Desktop 后重试脚本 |
| 启动后一直打不开 | `docker logs -f sxdevops-demo` 查看初始化进度 |
| 演示数据被观众改乱 | 恢复初始状态（见第五节第 3 条） |
| AI 助手提示无模型 | 确认容器环境变量含 `SXDEVOPS_DEMO_MODE=1`（旧镜像需重建） |
| 现场机器无网络 | 无影响——镜像包与数据全部离线；仅 `docker load` 需要本地 Docker |
